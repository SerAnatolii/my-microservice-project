## Опис структури проєкту

Цей проєкт налаштовує базову інфраструктуру на AWS за допомогою Terraform. Він включає:

- Синхронізацію стейт-файлів у S3 з використанням DynamoDB для блокування.
- Мережеву інфраструктуру (VPC) з публічними та приватними підмережами.
- ECR (Elastic Container Registry) для зберігання Docker-образів.

Структура проєкту:
- `main.tf`: Підключення модулів.
- `backend.tf`: Налаштування бекенду для стейтів (S3 + DynamoDB).
- `outputs.tf`: Загальне виведення ресурсів.
- `modules/s3-backend/`: Модуль для S3 та DynamoDB.
- `modules/vpc/`: Модуль для VPC.
- `modules/ecr/`: Модуль для ECR.

text## Пояснення кожного модуля

### s3-backend
- Створює S3-бакет для зберігання Terraform стейт-файлів з увімкненим версіонуванням та шифруванням.
- Створює DynamoDB таблицю для блокування стейтів, щоб уникнути конфліктів при паралельній роботі.

### vpc
- Створює VPC з вказаним CIDR блоком.
- Додає 3 публічні та 3 приватні підмережі в різних зонах доступності.
- Налаштовує Internet Gateway для публічних підмереж та NAT Gateway для приватних.
- Налаштовує таблиці маршрутів для правильної маршрутизації трафіку.

### ecr
- Створює ECR репозиторій для Docker-образів.
- Увімкнює автоматичне сканування образів на вразливості.
- Налаштовує базову політику доступу до репозиторію.
